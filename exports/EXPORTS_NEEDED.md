# What to export from Figma → drop into this `exports/` folder

The Figma MCP quota is used up, so I can't pull assets automatically. Please
export the frames below from Figma and save them here with the **exact filenames**.

## How to export (per frame)
1. In Figma, click the frame in the left layers panel (names below).
2. In the right panel → **Export** → click **+** → choose **PNG** → set **2x**.
3. Click **Export [frame]** and save into this `exports/` folder using the filename given.

Tip: You can select several frames and export them all at once.
